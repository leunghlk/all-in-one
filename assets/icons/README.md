## 📋 圖標使用說明

### 現有圖標（Emoji）
Emoji 圖標已在 `index.html` 中直接使用，支持所有現代瀏覽器。

### 新增圖標（圖片格式）
生成的圖標可以：
1. 下載並保存到 `assets/icons/` 目錄
2. 在 `index.html` 中使用 `<img>` 標籤引用
3. 或作為 CSS background-image 使用

### 圖標規範
- **尺寸**：建議 48x48px 或 96x96px
- **格式**：PNG（支持透明背景）
- **風格**：扁平化、現代化設計
- **色彩**：符合品牌色彩規範

## 🔄 更新圖標

如需更新儀表板圖標：

1. **選擇新的圖標設計**
2. **生成或創製圖標**
3. **更新 `index.html` 中的圖標引用**
4. **提交更改到 Git**

### 範例：替換圖標
```html
<!-- 原始 -->
<div class="card-icon work">📊</div>

<!-- 更新為圖片 -->
<div class="card-icon work">
  <img src="assets/icons/portfolio-analytics.png" alt="Portfolio Analytics" width="24" height="24">
</div>
```
