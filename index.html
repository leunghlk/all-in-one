隱私政策 · Privacy Policy

leungkathy 出品嘅呢個網站（all-in-one dashboard）係一個靜態網頁，由 GitHub Pages 託管。以下係你撳「隱私政策」會睇到嘅內容概要：

1. 我哋收集啲乜？

  • 本網站本身唔會主動收集任何個人資料（冇登入、冇表格、冇會員系統）。
  • 各個 dashboard 純粹响你部瀏覽器本地計數，數據唔會上傳去任何伺服器。

2. 第三方服務

  • GitHub Pages：託管網站，可能記錄標準伺服器日誌（IP 地址、瀏覽器類型、訪問時間），用作技術維護。詳情見 GitHub Privacy Statement。
  • 部分 dashboard 可能經由 Cloudflare Worker 等中轉代理提取公開市場數據（如股價、外匯），只讀取公開資訊，唔涉及你嘅個人資料。

3. Cookie 同追蹤

  • 本網站冇用第一方追蹤 cookie。GitHub Pages 或瀏覽器可能留有基本技術性緩存，但不會用於識別你嘅身份。

對隱私有疑問？可以電郵 leunghlk@gmail.com。
